# 02. Дизайн-система

Источник правды — `design/tokens/tokens.json` (формат близок к W3C Design Tokens). `design/tokens/tokens.css` генерируется из него: `node design/tools/build-tokens.mjs`. Тот же скрипт проверяет контраст и пишет отчёт в `design/tokens/contrast-report.txt`. Руками `tokens.css` не правим.

Имя CSS-переменной = путь токена через дефис: `color.ink.900` → `--color-ink-900`, `motion.duration.pour` → `--motion-duration-pour`. Алиасы (`{color.copper.600}`) превращаются в `var(--color-copper-600)`.

В компонентах используйте **семантические** токены (`--color-semantic-*`), а сырые шкалы — только в иллюстрациях и там, где у семантики нет имени.

## 1. Цвет

### Интерфейс

| Токен | Hex | Роль |
| --- | --- | --- |

| `ink-500` | `#56628A` | Приглушённый текст, подписи. 6:1 на белом, 5,1:1 на кафеле |
| `ink-300` | `#A7B0CA` | Неактивные иконки, разделители. **Не для текста** |

### Обратная связь

| Тип | Фон / текст | Иконка | Когда |
| --- | --- | --- | --- |
| Изменение (реакция) | `copper-50` / `copper-700` | иконка явления (`result-gas`, `result-color`…) | Что-то произошло |
| Ничего не произошло | `neutral-100 #EDF0F6` / `neutral-600` | `result-nothing` | Реакции нет — тоже результат |
| Успех | `success-100 #DDF3E6` / `success-600 #1A7046` | `check` | Верная надпись, сбылась гипотеза, пройдено |
| Открытие | `grape-50` / `grape-600` | `star` | Новое сочетание, новое вещество |
| Стоп-безопасность | `caution-100 #FFF0D9` / `caution-700 #A34A05`, рамка `caution-500` | `caution`, `shield` | Опасное сочетание, правило |
| Разрушительное | `danger-100` / `danger-600` | — | Только «удалить весь прогресс» на странице родителей. В лабе не используется |

**Правило:** цвет никогда не единственный сигнал. Каждая плашка = иконка + текст + цвет. Красный в лабе не используем совсем: он пугает и сливается с цветами веществ.

### Вещества и растворы (`color.substance.*`)

Жидкость рисуется цветом вещества с `--liquid-opacity: .85` поверх стекла. Значения подобраны по реальному виду:

| Токен | Hex | Вещество |
| --- | --- | --- |
| `water` | `#CDE9FB` | Вода и прозрачные растворы (соль, сахар, сода, уксус) |
| `cloudy-white` | `#EEF1F0` | Мутная взвесь (крахмал, мел); вместе с `--turbidity` |
| `iodine` | `#B5651D` | Раствор йода |
| `iodine-starch` | `#1F2570` | Йод + крахмал |
| `copper-sulfate` | `#3A8EDB` | Медный купорос |
| `permanganate` | `#8E1B8E` | Марганцовка |
| `caramel` | `#A0611C` | Сахар при нагреве |
| `cabbage` | `#7B4FB5` | Отвар краснокочанной капусты, нейтральный |
| `phenolphthalein-base` | `#E2408B` | Фенолфталеин в щёлочи |
| … | | полный список — в `tokens.json` |

Прозрачные бесцветные растворы чуть голубее воды не делаем: «растворилось» = прозрачно, как в уроке. Мутность передаётся слоем `turbidity` (белая вуаль + крупинки), а не только цветом.

### Шкала pH

`color.ph.1…14` — универсальный индикатор: красный (1) → оранжевый → жёлтый → зелёный (7–8) → сине-зелёный → синий → фиолетовый (14). Промежуточные значения — линейная интерполяция в OKLCH между соседними точками (в CSS: `color-mix(in oklch, var(--color-ph-3) 60%, var(--color-ph-4))`).

`color.ph-cabbage.*` — шкала краснокочанной капусты для урока «попробуй дома».

Рядом с цветом pH **всегда** число и слово: «pH 3 · кислая», «pH 7 · нейтральная», «pH 9 · щелочная» (границы 6,5 и 7,5).

### Контраст (проверено скриптом)

Все пары текста ≥ 4,5:1 (AA для обычного текста). Неречевые элементы (рамки, иконки-маркеры) ≥ 3:1. Отчёт — `design/tokens/contrast-report.txt`, в нём 30 пар. Скрипт завершается с ошибкой, если пара не проходит, — удобно поставить в CI.

## 2. Типографика

Шрифты бесплатные, лицензия OFL, полная кириллица, есть на Google Fonts:

- **Unbounded** (500–800) — заголовки H1–H3, название миссии, цифры на значках и номера шагов. Широкий, круглый, «научно-игровой», узнаваемый.
- **Golos Text** (400–800) — весь интерфейс и текст. Создан для русского интерфейса, отличная читаемость кириллицы, табличные цифры (`tnum`).

Подключение в продакшене:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Golos+Text:wght@400..800&family=Unbounded:wght@500..800&display=swap" rel="stylesheet">
```

Альтернатива без внешних запросов (лучше для детской приватности): самостоятельно хостить подмножество из `design/fonts/` (кириллица + латиница + стрелки, индексы, °, №; 50 и 69 КБ в WOFF). Рекомендую этот вариант для GitHub Pages: ни одного запроса к третьей стороне.

### Шкала

| Токен | Размер / межстрочный | Шрифт, начертание | Где |
| --- | --- | --- | --- |
| `display` | 56 / 60 | Unbounded 700, −0,02em | Экран награды, обложка урока |
| `h1` | 36 / 44 | Unbounded 700 | Заголовок страницы, модуля |
| `h2` | 28 / 36 | Unbounded 600 | Заголовок экрана урока, диалога |
| `h3` | 21 / 28 | Unbounded 600 | Заголовки панелей |
| `title` | 20 / 26 | Golos 700 | Цель миссии, заголовок карточки |
| `lg` | 20 / 30 | Golos 400 | Реплики Пипы в уроке |
| `md` | 18 / 27 | Golos 400 | **Основной текст**: объяснения, диалоги |
| `sm` | 16 / 23 | Golos 400–700 | Кнопки, подписи веществ, журнал |
| `xs` | 15 / 20 | Golos 500 | Вторичные подписи |
| `readout` | 28 / 32 | Golos 700, `tnum` | Показания термометра, pH, весов |

Правила:

- Основной текст для ребёнка — 18 px, не меньше 16 px.
- Подписи и метки — не меньше 14 px. 13 px допускается только для **дублирующих** меток, смысл которых уже передан иконкой или соседним текстом (клавиша-подсказка на кнопке действия, «есть дома» под иконкой домика, «новое»).
- Длина строки текста — до 38em (`--size-measure`).
- Unbounded — только для коротких заголовков до ~40 знаков. Абзацы им не набираем.
- Цифры в приборах и счётчиках — `font-variant-numeric: tabular-nums` (класс `hl-num`), чтобы при смене значения не прыгала ширина.
- Десятичный разделитель — запятая: «22,5 °C». Между числом и единицей — неразрывный пробел.
- Без капслока и разрядки.

## 4. Радиусы

Радиус растёт вместе с размером элемента: `xs 6` (метки, чипы) → `sm 10` (поля) → `md 14` (кнопки, вещества) → `lg 20` (панели) → `xl 28` (диалоги, пузырь Пипы) → `pill` (переключатели, прогресс). Не ставим один радиус на всё.

## 5. Контур и тени

- Контур нажимаемого — 2 px `ink-900`. У неактивного — 2 px `ink-200`/`ink-300` пунктиром (для действий).
- `shadow.lip` — плоская «губа» `0 3px 0 rgba(22,33,63,.18)` у всего, что нажимается. Hover: 4 px и подъём на 1 px. Active: 1 px и опускание на 2 px.
- `shadow.float` — единственная размытая тень, только у парящего: диалог, тост, пузырь Пипы, перетаскиваемый предмет, поповер.
- `shadow.inset` — утопленные поля.

## 6. Фокус

`--focus-ring: 0 0 0 3px lamp-400, 0 0 0 6px ink-900` — жёлтое кольцо с тёмной обводкой: виден и на белом, и на синем, и на дереве. Показываем только при `:focus-visible` (клавиатура), не при нажатии мышью или пальцем. Кольцо не обрезается: у контейнеров с `overflow: hidden` оставляйте внутренний отступ ≥ 6 px.

## 7. Движение

### Длительности

| Токен | Значение | Что |
| --- | --- | --- |
| `instant` | 100 мс | Нажатие кнопки |
| `fast` | 160 мс | Hover, фокус, тумблер, смена позы Пипы |
| `base` | 240 мс | Поповер, вкладки, раскрытие «копнуть глубже» |
| `slow` | 400 мс | Панели, диалог, пузырь Пипы |
| `pour` | 900 мс | Наливание и пересыпание, смена уровня |
| `effect` | 1600 мс | Типичный эффект реакции, смена цвета |
| `effect-long` | 3200 мс | Осадок, кристаллы, выпаривание (с ускорением «подождать») |

### Кривые

| Токен | Значение | Что |
| --- | --- | --- |
| `standard` | `cubic-bezier(.2,0,0,1)` | Всё по умолчанию |
| `enter` | `cubic-bezier(.05,.7,.1,1)` | Появление |
| `exit` | `cubic-bezier(.3,0,.8,.15)` | Исчезновение |
| `pop` | `cubic-bezier(.34,1.56,.64,1)` | Пузырь подсказки, значок, кристалл — с лёгким перелётом |
| `liquid` | `cubic-bezier(.45,.05,.25,1)` | Уровень и цвет жидкости |
| `settle` | `cubic-bezier(.55,0,.9,.5)` | Падение частиц, оседание |

### Сниженное движение

При `prefers-reduced-motion: reduce` `tokens.css` сжимает длительности (интерфейс — до 1 мс, эффекты — до 400–600 мс), а `effects.css` останавливает частицы и колебания. События всё равно **видны**: цвет меняется, уровень поднимается, осадок появляется — просто без пути и мерцания. Подробно — `05-effects.md`.

Также в лабе будет собственный переключатель «Спокойные эффекты» в настройках звука (для детей, которым мешает движение, но системная настройка не включена). Он ставит на `<html>` класс `reduce-motion` с тем же действием.

## 9. Брейкпоинты

| Токен | Ширина | Раскладка лабы |
| --- | --- | --- |
| `desktop` | ≥ 1280 | Три колонки: полка 248 · стол · журнал 328 |
| `tablet-landscape` | 1024–1279 | Полка 200 · стол; журнал выезжает справа по кнопке «Журнал» |

Плюс условие по высоте: при высоте < 800 px на ширине ≥ 1024 сцена и док становятся компактнее. CSS-переменные в `@media` не работают — пишите литералы.

## 10. Масштаб сцены `--u`

Посуда на столе рисуется в «натуральных» единицах (стакан 120 px, пробирка 48 px…) и умножается на `--u`. Брейкпоинты меняют только `--u` (0,85…1,12), а не отдельные размеры. Это гарантирует, что стакан всегда больше пробирки и пропорции сцены сохраняются.

## 11. Как применять

- **Одна яркая вещь на экране.** Если на экране уже есть жёлтая подсветка выбранного и синяя главная кнопка, третий яркий акцент (фиолетовый тост) появляется только по событию и уходит.
- **Главная кнопка одна** на область: «Проверить» в цели, «Записать в журнал» в результате, «Понятно» в диалоге.
- **Выбранное — всегда лампа.** Сосуд, вещество «в руке», вариант ответа, пресет количества: жёлтое кольцо 4 px + `lamp-100`. Не используем синий для выбора — синий значит «нажми».
- **Неактивное — пунктир**, а не только бледность: кнопка действия, которое сейчас невозможно, получает пунктирную рамку и остаётся читаемой (контраст текста ≥ 4,5).
- **Бирюза только для глубины**, фиолетовый только для открытий и наград, янтарь только для безопасности. Не берём эти цвета «для красоты».
- **Текст на дереве** — `ink-900` или `wood-700`. Белый текст на дереве не ставим.
