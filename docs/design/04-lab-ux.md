# 04. UX виртуальной лаборатории

Как устроен экран лабы, как ребёнок делает каждое действие тремя способами (перетаскивание, нажатия, клавиатура), как лаба показывает результат, останавливает опасное и ведёт по миссии. Макеты: `design/mockups/lab-*.html`, скриншоты: `design/screenshots/`.

Сверено с черновиком урока 1 (`docs/content/lesson-01.md`): миссия «Загадка белых порошков», подсказки трёх уровней (п. 4.9), детективная доска (п. 4.10), реакции на неожиданные действия (п. 4.11), остановки (п. 4.6.8).

## 1. Зоны экрана

```
┌──────────────────────────────── Верхняя панель 64 ─────────────────────────────────┐
│ ‹  [Миссия] Загадка белых порошков        💡Подсказки ◉  ⛏Копнуть глубже ○  🔊      │
├───────────┬──────────────────────────────────────────────────────┬─────────────────┤
│ ПОЛКА     │ ЦЕЛЬ МИССИИ (в песочнице — полка посуды и приборов)    │ ЖУРНАЛ          │
│ веществ   │ ┌────────────────────────────────────────────────────┐ │ наблюдений      │
│ 248       │ │ ◎ Подпиши все 5 банок  [А][Б]…  [Пипа, помоги][✓]  │ │ 328             │
│           │ └────────────────────────────────────────────────────┘ │                 │
│ банки на  │        ┌ пузырь Пипы ┐                                  │ детективная     │
│ досках    │        └─────────────┘                                  │ доска,          │
│           │   ПИПА   РАБОЧИЙ СТОЛ: сосуды, штатив, горелка, баня   │ гипотеза,       │
│           │ ════════════════════ столешница ═══════════════════════ │ что было,       │
│           │ ДОК ДЕЙСТВИЙ: [сосуд] содержимое                        │ вывод           │
│           │ Сделать   [Перемешать][Нагреть][Охладить][Подождать]…   │                 │
│           │ Наблюдать [Понюхать][Лупа][Термометр][pH] ┊[Отм.][Вылить]│                 │
└───────────┴──────────────────────────────────────────────────────┴─────────────────┘
```

| Зона | Что делает | Где |
| --- | --- | --- |
| Полка веществ | Откуда берём вещества. Группы, состояние «в руке», закрытые вещества | Слева (портрет — лента снизу) |
| Оборудование | Полка посуды и приборов на стене. Нажал — предмет встал на стол | Над столом (в миссии нужный набор уже стоит на столе, полки нет) |
| Рабочий стол | Сосуды, штатив, станции (горелка, ледяная баня, весы). Выбор сосуда, цель перетаскивания | Центр |
| Действия | Док под столом: всё, что можно сделать с выбранным сосудом | Под столом |
| Журнал | Гипотеза → что было → вывод; в миссии — детективная доска | Справа (< 1280 — выезжает) |
| Пипа и подсказки | Пипа стоит на столе слева, пузырь — над ней и не перекрывает выбранный сосуд | На столе слева |
| Цель миссии | Что надо сделать, сколько надписей наклеено, «Пипа, помоги», «Проверить» | Верх сцены (только миссия) |

Главная ось взгляда: **полка → стол → док → журнал**, слева направо и сверху вниз, как в настоящей лаборатории: взял, поставил, сделал, записал.

## 2. Раскладки

### Компьютер ≥ 1280 (макеты 1440×900)

Три колонки: полка 248 · сцена · журнал 328. Сцена: полка посуды (песочница) или цель (миссия), стол с масштабом `--u: 1` (1,12 при высоте ≥ 860), док в две строки. Клавиатурные подсказки на кнопках действий видны.

### Планшет альбомно 1024–1279 (макеты 1024×768)

Две колонки: полка 200 · сцена. Журнал — выезжающая справа панель 360 по кнопке «Журнал» в верхней панели; после записи в журнал на кнопке появляется точка-счётчик. В доке строки без подписей «Сделать / Наблюдать», шесть колонок. Цель миссии — в одну строку без подзаголовка. Карточка результата 380 px.

### Планшет портретно 768–1023 (скриншоты 768×1024)

Одна колонка: сцена на всю ширину, док под столом, **полка веществ — горизонтальная лента внизу** (под большим пальцем), журнал выезжает. Переключатели в верхней панели — только иконками. Цель миссии переносится в две строки. Карточка результата закрывает правую часть сцены; Пипа и выбранный сосуд остаются видны.

Телефоны вне рамок. При ширине < 768 показываем экран «Лаба работает на компьютере и планшете» с картинкой Пипы и ссылкой на уроки.

## 3. Базовая модель взаимодействия

Один принцип на всё: **«что» + «куда»**.

- **Перетаскивание**: тянем вещество/прибор/действие на сосуд.
- **Тап-тап** (основной способ на планшете и для мыши): нажал на вещество — оно «в руке» (кольцо лампы, ярлык «В руке», курсор-подсказка «Выбери сосуд»); нажал на сосуд — действие выполнено. Порядок можно и обратный: сначала выбрал сосуд, потом нажал вещество или действие.
- **Клавиатура**: Tab по зонам, стрелки внутри зоны, Enter/Пробел — выбрать, Esc — отменить выбор.

Выбранный сосуд — всегда один, он подписан в строке контекста дока. Действия дока применяются к нему.

### Перетаскивание: детали

- Порог начала: 6 px движения или 250 мс удержания (на планшете), чтобы не путать с тапом.
- Пока тянем: копия предмета под пальцем, смещённая на 24 px вверх (не закрывается пальцем), `shadow.float`; все подходящие сосуды получают пунктир (`is-drop-target`), неподходящие тускнеют.
- Над сосудом: сплошная лампа и подпись на ярлыке «Добавить сюда».
- Отпустили мимо: предмет плавно возвращается на место за 240 мс.
- Pointer Events (одинаково для мыши, пальца и пера), `touch-action: none` на перетаскиваемом.
- Нельзя перетащить из сосуда обратно в банку (урок 1, строка 47): банка «отталкивает» предмет, Пипа: «Обратно в банку ничего не возвращаем».

### Клавиатура

| Клавиша | Где | Что |
| --- | --- | --- |
| Tab / Shift+Tab | везде | Зоны по порядку: верхняя панель → полка → стол → док → журнал. Внутри зоны — один стоп (roving tabindex) |
| ← → ↑ ↓ | полка, стол, док | Между элементами зоны |
| Enter / Пробел | вещество, прибор | Взять в руку |
| Enter / Пробел | сосуд | Выбрать / применить то, что в руке |
| Esc | везде | Положить из руки, закрыть поповер, карточку, пузырь |
| M H C W F E | лаба | Перемешать, нагреть, охладить, подождать, фильтр, выпарить |
| S L T P | лаба | Понюхать, лупа, термометр, pH |
| Ctrl+Z | лаба | Отменить последний шаг |
| J | лаба | Открыть/закрыть журнал (< 1280) |
| ? | лаба | Попросить подсказку |

Однобуквенные клавиши работают, только когда фокус не в поле ввода и пользователь не выключил их в настройках (WCAG 2.1.4). Каждое изменение состояния сосуда объявляется через `aria-live="polite"`: «В стакан 2 добавлено 2 ложки соды. Пузырьки газа».

## 4. Сценарии действий

Во всех сценариях действия журналируются автоматически («что было»), а результат показывается иконкой + текстом + цветом.

### 4.1. Поставить посуду

Нажать предмет на полке посуды → он встаёт на ближайшее свободное место стола с коротким «опусканием» (240 мс) и сразу становится выбранным. Перетаскиванием — на конкретное место. Мест на столе 5 (компьютер) / 4 (планшет). Если мест нет — пустые места подсвечиваются пунктиром, Пипа: «Стол занят. Вылей и убери лишнюю посуду».

### 4.2. Добавить вещество в нужном количестве

1. Взять вещество (тап или начать тянуть).
2. Указать сосуд (тап или отпустить над ним).
3. Открывается поповер количества рядом с сосудом: `[−] 1 ложка [+]`, пресеты, «Добавить». Единица из данных вещества: порошки — ложки (порции), жидкости — мл или порции, реагенты пипеткой — капли.
4. «Добавить» → эффект пересыпания (ложка над горлышком, `fx/powder-stream`) или наливания (бутылка наклоняется, `fx/pour-stream`) 900 мс, уровень поднимается.
5. Вещество остаётся «в руке», чтобы добавить его в следующий сосуд одним тапом; Esc или тап по пустому месту — положить.

Быстрый путь для опытного: двойной тап по сосуду с веществом в руке — добавить последнее использованное количество без поповера.

Избыток и насыщение (по данным): нерастворившееся остаётся на дне слоем `powder`/`sediment`, в результате — «Соды многовато для такой порции воды. Добавь воды и перемешай» (урок 1, п. 4.11). Переполнение: «+» в поповере неактивна на максимуме, подпись «Больше не поместится».

В миссии урока 1 по требованию урока поповера нет: **1 тап = 1 порция** (п. 4.5). Количество показывается в строке контекста дока: «порошок В, вода 2 порции».

### 4.3. Нагреть

1. Выбрать сосуд → «Нагреть».
2. Если сосуд — пробирка: нужен держатель. Без держателя кнопка `aria-disabled`; по нажатию держатель на полке подсвечивается, Пипа: «Горячую пробирку держим только держателем. Возьми его!» (строка 44).
3. Сосуд переезжает на горелку (или ставится на неё перетаскиванием), пламя загорается, сетка краснеет (`--heat`), кнопка «Нагреть» в состоянии `running` с полосой времени и подписью «Стоп».
4. Нагрев идёт, пока действие активно (по уроку: «нагрев идёт, пока держишь» — на планшете удержание кнопки; отпустил — горелка гаснет). Эффекты по стадиям из данных вещества (плавление, пар, карамель).
5. Ярлык: «Пробирка 1 · греется» с пламенем.

### 4.4. Охладить

Сосуд ставится в ледяную баню (задняя половина бани под сосудом, передняя поверх — сосуд «в воде»). Иней `fx/frost` по краю, температура падает на термометре, если он в сосуде. Длительность — как у «Подождать».

### 4.5. Перемешать

Стеклянная палочка опускается в сосуд и делает 3 круга (1,8 с), жидкость колеблется (`fx-stir`), крупинки кружатся. Повторное нажатие — ещё 3 круга. Растворение у соды идёт «после 2–3 перемешиваний» (урок 1, строка 8): прогресс растворения виден по уменьшению горки порошка.

### 4.6. Подождать

Кнопка запускает ускоренное время (по уроку — 10 с реального = несколько минут в лабе). Над сценой — часы-плашка «Прошло 5 минут». Идёт оседание мути, кристаллы, остывание. Повторное нажатие — стоп. Во время ожидания остальные действия доступны.

### 4.7. Профильтровать

1. Выбрать сосуд со смесью → «Фильтр».
2. На стол ставится воронка с фильтром над пустым стаканом (если свободного стакана нет — Пипа просит поставить).
3. Смесь переливается в воронку, капает фильтрат (`--flow`, `--drip`), на фильтре остаётся осадок (`--residue`). 3,2 с, «Подождать» ускоряет.
4. Результат: в стакане — прозрачный раствор, на фильтре — нерастворимое. Оба можно исследовать дальше.

### 4.8. Выпарить

Раствор переливается в выпарительную чашку на горелке. Пар (`fx/steam`), уровень падает, на дне по одному появляются кристаллы (`fx-crystals`). Финал: «Вот и соль! Она никуда не девалась — просто пряталась в воде» (урок 1, строка 34). С «Подождать» — 3–4 с.

### 4.9. Понюхать правильно

1. Выбрать сосуд → «Понюхать».
2. Анимация «веером»: над сосудом появляется ладонь (иконка `smell` крупно) и делает 2–3 взмаха от горлышка к краю экрана; от горлышка тянутся волны `fx/smell`, если запах есть.
3. Подпись у сосуда: «Резкий кислый запах» / «Почти без запаха» / «Пахнет карамелью».
4. Другого способа понюхать в лабе нет — неправильный способ показывается только в уроке (экран Р4).

Запах не передаётся цветом: волны всегда одного цвета (`grape`), различие — в тексте.

### 4.10. Рассмотреть в лупу

1. Выбрать сосуд или банку → «Лупа» (или перетащить лупу на предмет).
2. Над предметом открывается круглое окно 200 px с узором крупинок (`lens/*`: кубики, кристаллы, мелкий порошок, сверхмелкий), рядом подпись: «Прозрачные кубики с ровными гранями».
3. Окно закрывается по тапу мимо или Esc. Работает на сухом порошке, банке и пробирке (урок 1, п. 4.5).

### 4.11. Измерить температуру

Действие «Термометр» → термометр опускается в сосуд и остаётся там (виден на рисунке), над сосудом — плашка показания `22 °C` (28 px, tnum), в журнал — запись. Если температура меняется (нагрев, реакция), число обновляется плавно раз в 0,5 с, рядом стрелка ↑/↓ и слово «теплее/холоднее». Через 4 с плашка сворачивается в чип на ярлыке сосуда («🌡 18 °C»). Повторный тап по «Термометр» — вынуть.

### 4.12. Измерить pH

Действие «pH» → полоска опускается в сосуд, кончик плавно окрашивается (1,6 с), затем плашка: «pH 3 · кислая среда» + шкала 1–14 с меткой. Число показывается целым (в продвинутом режиме — с десятыми). Цвет полоски — по шкале `color.ph.*`.

### 4.13. Магнит, весы

- **Магнит**: перетащить на сосуд или смесь — железные опилки «прилипают» к магниту и уходят из смеси. В доке не выводится (доступен на полке приборов, когда в наборе есть железо).
- **Весы**: поставить сосуд на весы — на дисплее масса в граммах (в MVP — «3 ложки ≈ 15 г»).

### 4.14. Отменить и очистить

- **Отменить** (кнопка в доке, Ctrl+Z) — шаг назад по истории сосуда. Глубина 10 шагов. Отменяется и запись в журнале «что было» (с пометкой «отменено», а не стирается молча).
- **Вылить** (в миссии — «Помыть») — сосуд пустеет с анимацией выливания 600 мс; подтверждение не нужно, потому что есть тост «Стакан 2 вымыт · Вернуть» на 6 с.
- Убрать посуду со стола — перетащить на полку посуды или долгое нажатие → «Убрать».
- «Начать заново» (миссия) — в меню верхней панели, с диалогом подтверждения: «Начать миссию заново? Журнал сохранится».

## 5. Результат опыта

Порядок показа после действия:

1. **Эффект** (0–3 с): то, что видно в сосуде. Это главное — карточка не появляется поверх эффекта.
2. **Ярлык сосуда** меняется сразу: «Стакан 1 · пузырьки».
3. **Карточка результата** (после эффекта, 400 мс `pop`) справа в сцене:
   - наблюдения: иконка + «Пузырьки газа», «Цвет: из бурого в тёмно-синий» с образцами цвета;
   - объяснение для ребёнка (2–3 предложения из данных правила);
   - «Копнуть глубже» — раскрыто, если включён переключатель; научное название чипом;
   - «Записать в журнал» (главная), «Ещё раз».
4. Пипа меняет позу: радуется (реакция), задумывается («ничего не произошло», неожиданность).

В песочнице для повторных и простых результатов вместо карточки — **тост** («Соль растворилась · Почему?»): карточка только для первого раза или по «Почему?». Это держит темп.

**Открытие** (новое сочетание в песочнице): тост с фиолетовой звездой «Открытие! Отвар капусты краснеет от кислоты · Почему?», счётчик открытий в журнале +1, при открытии нового вещества — карточка вещества с «новое».

### «Ничего не произошло»

Оформлено как полноценный результат: серо-синяя плашка `--nothing`, иконка `result-nothing`, Пипа задумалась, объяснение почему: «Соль с уксусом не реагирует: новых веществ нет. А растворилась чуть-чуть потому, что в уксусе много воды». В журнале — строка с той же иконкой. Слова «ошибка», «неправильно» не используем.

### Опасное сочетание — остановка

Срабатывает по правилу-остановке из данных (урок 1: нагрев йода без воды, строка 43; в песочнице — например, бытовые средства с кислотой в будущих модулях).

1. Действие **не выполняется**: эффект не начинается, в сосуде ничего не меняется.
2. Затемнение, диалог `--caution` (`role="alertdialog"`):
   - Пипа в очках с ладонью «стоп»;
   - «Лаба остановила опыт» + щит;
   - заголовок — что не так: «Йод так не нагреваем»;
   - почему, 1–2 фразы: «Сухой йод при нагреве даёт пары. Они вредны для глаз и горла»;
   - правило: «В настоящей лаборатории так не делают. И дома тоже»;
   - как можно (если есть безопасный вариант): «Нагреть можно, если в пробирке много воды, а йода — одна капля»;
   - кнопки: «Убрать йод из пробирки» (отмена последнего шага), «Понятно».
3. Ни рецепта, ни названий опасных продуктов, ни пропорций (`00-context.md`, «Безопасность контента»).
4. Звук — мягкий двойной тон, не сирена. Без тряски экрана и красного.
5. В журнал — запись «Остановлено: йод + нагрев» с иконкой щита. Значок «Знаток безопасности» — за чтение правил, а не за попытки опасного.

Для нарушений правил без опасности (нагрев без держателя, возврат в банку) диалог не нужен: короткая реплика Пипы `--warn` в пузыре и подсветка нужного предмета.

### Поток

```
Цель ──► Попытки (опыты) ──► Подписи на банках ──► Проверить ──► Успех
   ▲            │                                     │
   └── Подсказки 1 → 2 → 3 ◄── «Пипа, помоги» / 60 с без действий
```

1. **Цель.** На старте — пузырь Пипы с сюжетом (тексты урока М1) и панель цели. Набор веществ и посуды уже на столе: штатив с пятью пробирками А–Д, горелка, держатель, флаконы воды, уксуса, йода.
2. **Попытки.** Любые опыты, любой порядок (урок принимает любой путь). Каждый опыт заполняет ячейку детективной доски.
3. **Подписи.** Надпись на банку — перетащить чип вещества из набора надписей на банку или тап по банке → выбрать из списка. Можно когда угодно, можно переклеить. На банке появляется плашка с карандашом «мел».
4. **Проверить** (активна, когда подписаны все пять). Проверка без счёта ошибок: каждая банка получает реплику; верная — зелёная плашка с галочкой и настоящей надписью; неверная с противоречием — Пипа ссылается на ячейку доски («Но от йода она не посинела») и подсвечивает её; неверная без наблюдений — «Про банку В мы пока ничего не знаем. Проведи опыт». Числа «3 из 5» нет (урок 1, п. 4.8).
5. **Успех.** Пипа радуется, «Опыт закончен — моем руки» (тап по раковине), экран «Твои доказательства», карточки веществ, значок «Сыщик порошков».

### Подсказки трёх уровней

Вызов — кнопка «Пипа, помоги» в цели (и клавиша ?). Через 60 с бездействия кнопка мягко пульсирует, но пузырь сам **не** выскакивает (урок 1, п. 4.9). Подсказка зависит от того, что уже на доске.

| Уровень | Тип | Вид |
| --- | --- | --- |
| 1 | Наводящий вопрос | Пузырь, Пипа задумалась, точки ●○○. «Ещё подсказку» / «Пока не надо» |
| 2 | Что сделать | Пузырь, Пипа объясняет, ●●○. Нужный сосуд и действие подсвечиваются кольцом лампы, остальное приглушено (`is-dim`) |
| 3 | Почти ответ | ●●●. Подсвечивается ячейка доски, которую надо заполнить. Опыт всё равно делает ребёнок |

Подсказки не уменьшают награду. Переключатель «Подсказки» выкл. не отключает кнопку «Пипа, помоги».

### Журнал «гипотеза → опыт → вывод»

1. **Гипотеза** (по желанию): перед опытом, если подсказки включены, у сосуда появляется чип-вопрос «Как думаешь, что будет?» с вариантами из данных проверки (зашипит / не зашипит / не знаю). Можно пропустить — чип исчезает при следующем действии.
2. **Опыт** записывается сам: «Банка Б + уксус».
3. **Наблюдение**: ребёнок выбирает чип «что увидел». Если чип не совпадает с результатом — Пипа: «Посмотри ещё раз: были пузырьки?» и эффект повторяется (урок 1, п. 4.10).
4. **Вывод**: при наклейке надписи — чип «Потому что…» со ссылками на ячейки банки.

### Поворот сюжета

Второе шипение (мел после соды) — Пипа задумалась: «Опять шипит?! Но сода у нас одна… Значит, шипят двое». Подсказка не включается.

## 7. Песочница

- Полка с открытыми веществами по группам, закрытые — внизу с замком и номером урока.
- Полка посуды и приборов над столом; стол с 5 местами.
- Журнал — свободная форма: гипотеза по желанию, «что было» автоматически, «вывод» чипами; внизу счётчик открытий.
- **Открытие нового вещества.** Когда реакция даёт новое вещество (например, известковая вода мутнеет от углекислого газа): эффект → тост-открытие → карточка вещества с меткой «новое» и иконкой «есть дома / только в лабе» → вещество встаёт на полку с анимацией «появления» (pop + искры, один раз).
- Идеи с экрана награды урока («Смешай крахмал с водой и нагрей») — в пустом журнале как подсказки «Попробуй».

## 9. Звук

Каждому эффекту — короткий звук (шипение двух громкостей, бульканье, звон стекла, мягкий «успех», двойной тон остановки). Одна кнопка в верхней панели выключает всё, состояние сохраняется. Без фоновой музыки. Звук никогда не единственный сигнал.

## 10. Доступность — сводка

- Цели касания ≥ 44 px (проверяется скриптом `design/tools/screenshots.mjs`).
- Фокус виден всегда при клавиатуре, порядок Tab по зонам.
- Каждое изменение сосуда — текстом в `aria-live`, состояние — в `aria-label` сосуда.
- Результат: иконка + текст + цвет. Шкала pH — число + слово.
- Сниженное движение: эффекты без частиц, итоговое состояние сразу (`05-effects.md`).
- Перетаскивание всегда дублируется тап-тапом и клавиатурой (WCAG 2.5.7).
- Тексты из данных: внутри SVG текста нет; буквы банок и пробирок, подписи и числа — HTML поверх рисунка (читаются скринридером и переводятся).
