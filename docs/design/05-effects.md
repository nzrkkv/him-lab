# 05. Визуальные эффекты

Как выглядят и как делаются эффекты опытов. Эталон — `design/components/effects.css` и слои SVG-ассетов (`design/assets/README.md`). Живые образцы — `design/preview/index.html`, раздел «Эффекты».

## Общий подход

**SVG + CSS-переменные + CSS-анимации.** Canvas не нужен для MVP: в сцене одновременно 3–5 сосудов, частиц немного, а SVG даёт чёткий контур на любом экране, доступность (`aria-label`) и простую отладку. Это совпадает с решением в технической спецификации (`docs/spec/01-product.md`, риск R-09: «SVG с анимацией через CSS-переменные, лимит частиц»).

Движок задаёт **состояние** сосуда переменными на корневом `<svg>`:

| Переменная | Диапазон | Слой |
| --- | --- | --- |
| `--level` | 0…1 | `liquid` — уровень |
| `--liquid-color` | цвет | `liquid-body` |
| `--turbidity`, `--turbidity-color` | 0…1, цвет | `turbidity` — муть |
| `--foam` | 0…1 | `foam` |
| `--sediment`, `--sediment-color` | 0…1, цвет | `sediment` — осадок |
| `--powder`, `--powder-color` | 0…1, цвет | `powder` — сухой порошок |
| `--bubbles` | 0…1 | `bubbles` |
| `--crystals`, `--crystal-color` | 0…1, цвет | `crystals` |
| `--heat`, `--flame` | 0…1 | горелка |
| `--temp`, `--ph-color` | 0…1, цвет | термометр, pH-полоска |

…и добавляет **класс эффекта** (`fx-fizz`, `fx-settle`…) на время процесса. Переходы между состояниями (уровень, цвет, муть) идут через `transition` сами; циклические анимации (пузырьки, пар) — через `@keyframes`.

Правило: эффект не меняет геометрию SVG и не создаёт DOM-узлы на каждый кадр. Частицы уже нарисованы в ассете (например, 10 пузырьков в стакане), анимация только двигает их.

### Бюджет производительности (эталон — iPad 9 / Android-планшет 2020 года, 60 Гц)

- Анимируем только `transform` и `opacity` (и `fill` у одного слоя на смене цвета). Никаких `filter: blur` в анимации, никаких анимаций `width/height/top`.
- Не больше **3 одновременно активных эффектов** в сцене. Четвёртый ждёт в очереди или запускается без частиц.
- Не больше **60 анимируемых элементов** на сцене одновременно (пузырьки + пар + крупинки).
- `will-change: transform` — только на слое `liquid` и только во время эффекта.
- Цель: кадр ≤ 8 мс на эталоне, 0 долгих задач > 50 мс при запуске эффекта. Проверка — Performance-панель Chrome с 4× CPU throttling.
- Если `navigator.hardwareConcurrency ≤ 4` или пользователь включил «Спокойные эффекты» — режим «облегчённый»: частиц вдвое меньше, пар — 1 струя.

### Сниженное движение (`prefers-reduced-motion: reduce` или класс `html.reduce-motion`)

Цель — **событие остаётся видимым**, исчезает только движение:

- длительности интерфейса → 1 мс, эффектов → 400–600 мс (`tokens.css`);
- частицы (пузырьки, пар, крупинки, волны запаха) замирают в одном кадре — статичный «снимок» явления;
- колебания и подпрыгивания выключены;
- цвет меняется плавным кроссфейдом 400 мс, уровень — 200 мс;
- иконка и текст результата появляются как обычно.

## Эффекты

Для каждого: что видно · длительность и кривая · частицы · реализация · вариант для сниженного движения.

### 1. Наливание

- **Видно:** бутылка (или мерный цилиндр) наклоняется над горлышком сосуда на 60° за 240 мс; из горлышка бутылки вниз идёт струя `fx/pour-stream` цвета жидкости; уровень в сосуде поднимается; на поверхности 2–3 брызги `fx/splash` в первые 200 мс; бутылка возвращается.
- **Время:** наклон 240 мс `enter` → струя `--motion-duration-pour` 900 мс → возврат 240 мс `exit`. Уровень `--level` меняется за 900 мс `liquid` с задержкой 120 мс (сначала струя долетает).
- **Частицы:** брызги — 4 кружка, один раз.
- **Как:** бутылка — HTML-обёртка с `transform: rotate()` и `transform-origin` у дна; струя — `fx/pour-stream.svg`, растянутая по высоте между горлышком (`data-mouth` сосуда) и бутылкой, появляется `scaleY 0→1` (`.fx-pour-stream`). Цвет — `--liquid-color`.
- **Пипетка:** капли `fx/drop` падают по одной (300 мс на каплю, `settle`), на поверхности — маленький круг-волна.
- **Сниженное движение:** без наклона и струи; уровень поднимается за 200 мс, в момент добавления у горлышка на 400 мс появляется статичная капля.

### 2. Пересыпание порошка

- **Видно:** ложка с горкой (`--powder: 1`) переезжает к горлышку, наклоняется; поток крупинок `fx/powder-stream`; на дне растёт горка `powder`.
- **Время:** 900 мс; горка `--powder 0→1` за 600 мс `settle` с задержкой 300 мс.
- **Частицы:** 28 крупинок в спрайте, падают циклом 800 мс.
- **Как:** CSS `@keyframes hl-grain-fall`; горка — `transform: scale(var(--powder))` от дна.
- **Сниженное движение:** горка появляется сразу.

### 3. Растворение

- **Видно:** после перемешивания горка порошка уменьшается, вода на миг слегка мутнеет (вуаль 0 → 0,7 → 0), затем становится прозрачной. Цвет раствора — по данным (обычно прозрачный).
- **Время:** соль, сахар — 1,6 с; сода — каждый круг перемешивания уменьшает горку на треть (урок 1: «после 2–3 перемешиваний»).
- **Как:** `--powder` → 0 (`transition` 3,2 с `settle`), класс `fx-dissolve` даёт вспышку мути (`@keyframes hl-dissolve-cloud`).
- **Насыщение:** горка уменьшается до остатка (`--powder: 0.3`) и дальше не уходит; подпись «Больше не растворяется».
- **Сниженное движение:** без вспышки мути, горка уходит за 400 мс.

### 4. Пузырьки газа

- **Видно:** кружки поднимаются со дна к поверхности, слегка покачиваясь, исчезают у поверхности.
- **Две интенсивности (урок 1, п. 8.4):**
  - **бурно** (сода + уксус): `fx-fizz fx-fizz--strong`, цикл 0,7–1 с, все 10 пузырьков, пена до середины, затухание за 3 с;
  - **спокойно** (мел + уксус): `fx-fizz`, цикл 1,1–1,7 с, `--bubbles: 0.6`, без пены, длится 6 с.
- **Частицы:** 8–10 на сосуд, у каждого `--i` (сдвиг фазы) и `--d` (разброс скорости).
- **Как:** `@keyframes hl-rise` на `.hl-bubble`, высота подъёма `--rise` (по умолчанию 90 px в единицах ассета). Затухание — движок снижает `--bubbles` к 0 (transition `opacity`).
- **Звук:** шипение двух громкостей.
- **Сниженное движение:** пузырьки видны неподвижно (снимок), исчезают по `--bubbles`.

### 5. Пена

- **Видно:** шапка из белых кругов на поверхности; растёт и опадает.
- **Время:** рост 600 мс `pop`, держится 1,5 с, опадает 1,6 с `liquid`. Перелив через край (урок 1, строка 39): пена поднимается выше края на 20 %, по наружной стенке стекают 2 потёка, через 2 с «лаба вытирает» — потёки исчезают.
- **Как:** слой `foam` двигается вместе с уровнем, `--foam` управляет прозрачностью; лёгкое колыхание `hl-foam-wobble`. Перелив — отдельный спрайт поверх сосуда (в ассетах не нарисован, см. открытые вопросы).
- **Сниженное движение:** пена появляется и исчезает кроссфейдом.

### 6. Смена цвета

- **Видно:** капля реагента окрашивает место падения, цвет расползается от точки падения к краям, затем весь объём ровного нового цвета.
- **Время:** 1,6 с `liquid`. Йод + крахмал — мгновенно (400 мс) — это и есть «примета».
- **Как (MVP):** `transition: fill` у `liquid-body` с одного цвета на другой. **Расползание** — дополнительный круг цвета-цели под `clipPath` сосуда, `scale 0→3` от точки падения за 1,2 с, затем `fill` основного тела догоняет.
- **Индикатор по pH:** цвет вычисляется из `pH` по шкале `color.ph.*` (или `ph-cabbage.*`) интерполяцией в OKLCH между соседними точками (`color-mix(in oklch, …)`); при нейтрализации pH меняется постепенно, и цвет плавно идёт по шкале через промежуточные (красный → оранжевый → жёлтый → зелёный), а не прыгает. Шаг обновления 100 мс, `transition` 300 мс.
- **Образцы «было → стало»** показываются в карточке результата квадратиками с рамкой — для тех, кто не заметил.
- **Сниженное движение:** без расползания, кроссфейд 400 мс.

### 7. Образование и оседание осадка

- **Видно:** в прозрачной жидкости появляется муть (белая вуаль + крупинки), потом крупинки опускаются, на дне растёт слой осадка с неровной кромкой, жидкость над ним светлеет.
- **Время:** появление мути 1,6 с; оседание 3,2 с `settle` (с «Подождать» — ускоренно). Песок оседает почти сразу (600 мс).
- **Как:** `--turbidity` 0→0,85 (муть), затем одновременно `--turbidity` 0,85→0,1 и `--sediment` 0→1 (`scaleY` от дна); крупинки в слое `sediment` падают `@keyframes hl-settle` (`fx-settle`).
- **Взвесь крахмала/мела** (урок 1): сразу `--turbidity: 0.85`, жидкость `cloudy-white`; при «Подождать» — оседание.
- **Сниженное движение:** муть и слой меняются кроссфейдом, без падения крупинок.

### 8. Пар

- **Видно:** 3 белые извилистые струйки с тонким тёмным контуром (видно на светлом фоне) поднимаются над горлышком, вытягиваются и тают.
- **Время:** цикл 2,4 с, сдвиг фаз 0,8 с, пока идёт кипение или выпаривание.
- **Как:** спрайт `fx/steam.svg` над `data-mouth` сосуда, `@keyframes hl-wisp` (`translateY` + `scaleY` + `opacity`).
- **Точность:** подпись — «Пошёл пар» только про кипение; «облачко над чайником — капельки» объясняется в «копнуть глубже» (урок 1, Р3).
- **Сниженное движение:** статичные струйки с прозрачностью 0,9.

### 9. Рост кристаллов

- **Видно:** при выпаривании или охлаждении насыщенного раствора на дне и стенках по одному появляются кристаллы (кубики соли, призмы сахара, синие ромбы купороса), растут до полного размера.
- **Время:** 3,2 с; каждый кристалл — `pop` 500 мс, три волны с задержками 0 / 0,6 / 1,2 с.
- **Как:** слой `crystals` (выпарительная чашка) или спрайты `fx/crystal` в позициях из данных; `@keyframes hl-crystal-pop` (`fx-crystals`). Цвет — `--crystal-color`.
- **Сниженное движение:** кристаллы появляются все сразу кроссфейдом.

### 10. Нагрев

- **Видно:** пламя горелки загорается (`--flame 0→1`, 240 мс) и мягко колышется; сетка над пламенем краснеет (`--heat`); над сосудом — волны тепла `fx/heat-waves` (оранжевые), пока температура растёт; ярлык «греется» с иконкой пламени.
- **Время:** колыхание пламени — цикл 0,9 с, бесконечно, пока горит; `--heat` 1,6 с.
- **Как:** `@keyframes hl-flicker` на `.hl-flame` (`scale` от основания).
- **Сниженное движение:** пламя статичное, волны тепла неподвижны.

### 11. Охлаждение

- **Видно:** сосуд в ледяной бане, по краю сосуда — 3–4 снежинки `fx/frost`, медленно появляются и пропадают; жидкость чуть темнеет к голубому (смешивание с `cold` 10 %); при замерзании воды — уровень становится «льдом» (`--liquid-color: substance.ice`, без волны поверхности).
- **Время:** снежинки — цикл 2,4 с; охлаждение — по шкале «Подождать».
- **Сниженное движение:** снежинки статичны.

### 12. Индикатор запаха

- **Видно:** при «Понюхать» — ладонь делает 2–3 взмаха над сосудом; если запах есть, от горлышка тянутся 3 пунктирные волны `fx/smell` (фиолетовые), дрейфуют в сторону и тают; подпись «Резкий кислый запах». Если запаха нет — только ладонь и подпись «Почти без запаха».
- **Время:** взмахи 3 × 400 мс; волны — цикл 2,2 с, 2 цикла.
- **Как:** `@keyframes hl-wave-drift`; ладонь — иконка `smell`/`hand` в HTML-обёртке с `rotate`.
- **Важно:** запах — всегда текст. Цвет волн одинаковый для всех запахов.
- **Сниженное движение:** волны и ладонь статично на 1,5 с.

### 13. Показания термометра

- **Видно:** термометр опущен в сосуд, красный столбик плавно идёт вверх/вниз; над сосудом плашка «22 °C» (28 px, tnum) со стрелкой ↑/↓ и словом «теплее/холоднее».
- **Время:** столбик — `transition` 600 мс `liquid` на каждое изменение; число обновляется раз в 0,5 с шагом 0,5 °C.
- **Как:** `--temp` (0…1 от шкалы 0–100 °C; для льда — шкала −20…100), слой `column`.
- **Сниженное движение:** столбик и число обновляются без анимации.

### 14. pH-полоска

- **Видно:** полоска опускается в сосуд (300 мс), кончик окрашивается из жёлтого (сухая) в цвет pH снизу вверх, затем плашка «pH 3 · кислая» со шкалой и меткой.
- **Время:** окрашивание 1,6 с `liquid`; плашка — после окрашивания, `pop` 400 мс.
- **Как:** `--ph-color` у слоя `pad` с `transition: fill`; метка шкалы — `--ph` (позиция `left`).
- **Сниженное движение:** окрашивание 400 мс, полоска не «опускается», а появляется на месте.

### 15. Плавление и обугливание (сахар, урок 1)

- **Видно:** белая горка → прозрачная лужица (уровень растёт, горка исчезает) → жёлтая → коричневая (`caramel`) + запах карамели → чёрная, пузыри, дымок (серые струйки `steam` с `--smoke` цветом), включается вытяжка (иконка в углу сцены).
- **Время:** стадии по данным вещества, пока идёт нагрев.
- **Сниженное движение:** стадии кроссфейдом.

### 16. Остановка опыта

- **Видно:** эффект не запускается. Затемнение 55 % за 240 мс, диалог появляется `pop` 400 мс. Пипа меняет позу на «предупреждает».
- **Никаких** тряски, мигания, красного.
- **Сниженное движение:** диалог без масштабирования, только прозрачность.

### 17. Награда и открытие

- **Значок:** появляется в центре `scale 0.6→1` с `pop` 400 мс, 6 искр `fx/sparkle` разлетаются на 40 px и гаснут за 800 мс. Один раз.
- **Новое вещество:** банка «выезжает» на полку `translateY(-12px)→0` + 3 искры.
- **Сниженное движение:** без искр и масштаба, только кроссфейд.

## Что сделать во фронтенде

1. Функция `setVesselState(svg, state)` — переводит модель сосуда (уровень, цвет, муть, осадок…) в CSS-переменные. Цвет жидкости при смеси — усреднение в OKLCH по долям (простое правило для MVP).
2. Функция `playEffect(svg, name, opts)` — добавляет класс `fx-*`, ставит таймер снятия, держит очередь (не больше 3 одновременно).
3. Слушатель `matchMedia('(prefers-reduced-motion: reduce)')` + настройка «Спокойные эффекты» → класс `reduce-motion` на `<html>` и облегчённые параметры для `playEffect`.
4. Позиции наложений (струя, пар, термометр) — из атрибутов `data-mouth`, `data-base`, `data-fill-top/bottom` ассета, пересчитанные через `getBoundingClientRect()` и `viewBox`.
