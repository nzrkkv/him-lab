# 03. Компоненты

Эталонная вёрстка — `design/components/components.css` (общие компоненты) и `design/components/lab.css` (лаба). Классы с префиксом `hl-`, модификаторы через `--`, состояния — нативными псевдоклассами и ARIA-атрибутами. Классы `.is-hover`, `.is-active`, `.is-focus`, `.is-selected` нужны только для статичного показа в макетах и preview; в продукте их заменяют `:hover`, `:active`, `:focus-visible`, `aria-*`.

Живые образцы всех состояний — `design/preview/index.html`, раздел «Компоненты».

Общие правила для всех нажимаемых элементов:

| Состояние | Как выглядит | Чем задаётся |
| --- | --- | --- |
| default | Контур 2 px `ink-900`, губа 3 px снизу | — |
| hover | Подъём на 1 px, губа 4 px, фон светлее (`copper-50`) | `:hover` (только устройства с hover) |
| active | Опускание на 2 px, губа 1 px, фон `copper-100` | `:active` |
| focus | Кольцо `lamp-400` 3 px + `ink-900` 3 px снаружи | `:focus-visible` |
| selected | Кольцо `lamp-400` 4 px, фон `lamp-100` | `aria-pressed`, `aria-selected`, `aria-checked` |
| disabled | Фон `ink-100`/`bench-top`, текст `ink-500`/`ink-700` (≥ 4,5:1), рамка `ink-200`, без губы; у действий — пунктир | `disabled` или `aria-disabled="true"` |

`aria-disabled` предпочтительнее `disabled` там, где по нажатию нужно объяснить, **почему** нельзя (например, «Нагреть» без держателя: Пипа подсказывает). Элемент с `aria-disabled` остаётся в порядке Tab.

Минимальная цель касания — 44×44 px, обычная — 48. Автотест в `design/tools` (скрипт скриншотов) проверяет это на всех макетах.

| Вариант | Класс | Когда |

## 2. Карточка `.hl-card`

- Статичная: белая, рамка 2 px `ink-200`, радиус 20, без тени.
- `--interactive`: рамка `ink-900`, губа; hover — подъём 2 px; active — опускание; selected — кольцо лампы; disabled — фон `tile-50`, рамка `ink-200`.
- Отступ 20 (16 на планшете).

## 3. Вкладки `.hl-tabs` / `.hl-tab`

Сегментированный контрол на подложке `ink-100`, радиус 14, вкладка 44 px. Выбранная — белая с контуром `ink-900` и губой. Hover — полупрозрачный белый. `--wood` — вариант для полки (подложка из дерева).

Разметка: `role="tablist"` + `role="tab"` + `aria-selected`. Стрелки ← → переключают вкладки, Tab уходит из группы.

## 4. Переключатель `.hl-switch` (подсказки, «копнуть глубже»)

Таблетка 52×32, ползунок 22. Выключено: дорожка `ink-100`. Включено: «Подсказки» — `copper-600`, «Копнуть глубже» — `deep-600` (модификатор `--deep`). Ползунок едет с кривой `pop` за 160 мс.

Слева иконка + подпись: «Подсказки» (`hint`), «Копнуть глубже» (`deeper`). На ширине < 1280 подпись «Глубже», на < 1024 — только иконка, имя переключателя остаётся в `aria-label`.

Разметка: `<button role="switch" aria-checked="true|false" aria-label="…">`. Пробел и Enter переключают.

Поведение:
- **Подсказки выкл.** — Пипа не предлагает подсказок сама и кнопка «Пипа, помоги» остаётся, но реплики-комментарии к опытам короче (только итог). Безопасность и «ничего не произошло» показываются всегда.
- **Копнуть глубже вкл.** — блоки `.hl-deeper` в результатах раскрыты по умолчанию, научные названия показываются чипами. Выкл. — блоки свёрнуты, но доступны по нажатию.

Состояние обоих переключателей хранится в браузере и общее для уроков и лабы.

Состояния:

## 6. Выбор количества `.hl-qty`

Появляется в поповере (`.hl-popover`) после того, как вещество выбрано и указан сосуд.

```
[ − ] [ 2  ложки ] [ + ]     пресеты: (1) (2) (3) (5)
       [ Отмена ]  [ Добавить ]
```

- Кнопки −/+ 48×48, значение 132×48 на подложке `lamp-100`: число 20 px + единица 14 px («ложки», «капли», «мл», «порции»), единица склоняется.
- Пресеты — чипы 44×44, выбранный с кольцом лампы.
- Граница: на минимуме «−» неактивна; на максимуме сосуда «+» неактивна и под значением подпись «Больше не поместится».
- Клавиатура: ↑/→ и ↓/← меняют на шаг, цифры 1–9 — сразу значение, Enter — «Добавить», Esc — отмена.
- Разметка значения: `role="spinbutton"` с `aria-valuenow`, `aria-valuetext="2 ложки"`.
- По умолчанию предложено последнее использованное количество этого вещества, при первом — 1.

## 7. Палитра действий `.hl-dock` + `.hl-act`

Док — «передняя кромка стола» под сценой (фон `bench-edge`).

```
[ Пробирка В ] порошок В, вода 2 порции
Сделать    [Перемешать][Нагреть][Охладить][Подождать][Фильтр][Выпарить]
Наблюдать  [Понюхать][Лупа][Термометр][pH] ┊ [Отменить][Вылить]
```

- Строка контекста: какой сосуд выбран (плашка лампы) и что в нём. Без выбранного сосуда: «Выбери сосуд на столе» и все действия `aria-disabled`.
- Кнопка действия: иконка 30 над подписью 15 px Golos 700, высота 62 (60 компактно), ширина — колонка сетки. Цвет иконки по группе: тепло — `#D9480F`, холод — `#2A80C2`, наблюдение — `deep-600`, остальное — `copper-600`.
- Клавиша-подсказка в правом верхнем углу (13 px, только ≥ 1280 и при наличии клавиатуры).
- «Отменить» и «Вылить» — тихие (`--quiet`), отделены пунктиром.
- В миссии в доке только действия, нужные для миссии (5), — меньше выбор, проще решение.

| Состояние | Вид |
| --- | --- |
| default / hover / active / focus | Общие правила |
| selected | Действие ждёт цель (например, выбран «Термометр», надо коснуться сосуда): кольцо лампы |
| running | Фон `lamp-100`, полоса прогресса сверху (`--progress`), `aria-busy="true"`. Повторное нажатие — «Стоп» для «Нагреть» и «Подождать» |
| disabled (невозможно сейчас) | Пунктирная рамка `ink-300`, фон `bench-top`, текст `ink-700`. По нажатию — короткое объяснение Пипы: «Нагреть можно только в держателе» |

## 8. Сосуд на столе `.hl-ware`

Кнопка-обёртка вокруг инлайнового SVG сосуда (`design/assets/equipment/*`), под ним ярлык `.hl-ware__tag` («Стакан 2», «Пробирка В»), к ярлыку крепятся чипы показаний (`.hl-ware__chip`: «18 °C»).

| Состояние | Вид |
| --- | --- |
| default | Сосуд на столе |
| hover | Ярлык становится белым с рамкой |
| selected | Подложка `lamp` 55 % с рамкой 3 px `lamp-400`, ярлык жёлтый, `aria-pressed="true"` |
| drop-target | Во время перетаскивания: пунктирная рамка `ink-900` на белой подложке; под пальцем — сплошная лампа |
| dim | 40 % — во время пошаговой подсказки, чтобы выделить нужный сосуд |
| busy | Идёт эффект: ярлык с иконкой процесса («Стакан 3 · кипит» с пламенем) |
| full | При попытке добавить больше — короткое покачивание и подпись «Больше не поместится» |

`aria-label` описывает содержимое и состояние словами: «Стакан 1: вода, 3 ложки соды. Пузырьки газа».

Пустое место на столе — `.hl-slot` (пунктир, подпись «Свободное место»; при перетаскивании — `is-target`).

## 9. Журнал наблюдений `.hl-journal`

Правая колонка 328 px на бумаге в клетку (на планшете — выезжающая панель 360 px).

Секции `.hl-jsec`, каждая на белой карточке:

1. **Гипотеза** (номер «?») — фраза с выпадающими чипами `.hl-pick`: «Если капнуть уксус в отвар капусты, цвет **[станет красным ▾]**».
2. **Что было** (иконка глаза) — строки `.hl-logline`: иконка результата 32 + «Стакан 2: капуста + уксус — **стал малиновым**» + мелкая строка подробностей.
3. **Вывод** («!») — фраза с чипами: «Отвар капусты **[краснеет ▾]** от **[кислоты ▾]**».
4. **Открытия** (песочница) — счётчик «7 из 40» и подсказка, что попробовать.

В миссии сверху — **детективная доска** `.hl-grid`: строки — проверки (лупа, вода, уксус, йод, нагрев), столбцы — банки А–Д. Ячейка: пусто (пунктир) или иконка результата на цветной подложке. Новая запись — кольцо лампы на 2 с. Под таблицей — легенда иконок. Для скринридера у каждой ячейки текст («растворилось»), у таблицы — `caption`.

Пустое состояние: пунктирная карточка «Сделай опыт — и выбери, что получилось».

Писать с клавиатуры ничего не нужно: всё заполняется чипами (решение урока 1, п. 4.10).

## 10. Пузырь подсказки Пипы `.hl-speech`

- Белый, рамка 2 px `ink-900`, радиус 28, `shadow.float`, хвостик к Пипе (`--tail-left` или `--tail-bottom`, позиция `--tail-x`/`--tail-y`).
- Шапка: «Пипа» (Unbounded 15, `guide-shade`) + уровень подсказки «Подсказка 1 из 3 ●○○».
- Текст 18/26, до 3 строк. Длиннее — делим на две реплики.
- Действия: «Ещё подсказку» (вторичная), «Пока не надо» (тихая). На 3 уровне вместо «Ещё подсказку» — «Показать, где» (подсвечивает сосуд).
- Ширина до 400 px. Не перекрывает выбранный сосуд и цель миссии: ставится над Пипой, левее штатива.
- `--warn`: рамка `caution-700` — для реплик безопасности без остановки опыта.
- `role="status"`, `aria-live="polite"`: скринридер прочитает подсказку, не перебивая.
- Появление: `fx-pop-in` 400 мс, кривая `pop`. Закрывается по «Пока не надо», Esc или следующему действию.

## 11. Карточка результата `.hl-result`

Появляется в сцене справа (не модально) после эффекта.

1. Мелкий заголовок: «Пробирка В + раствор йода».
2. Заголовок Unbounded 24: «Йод нашёл крахмал!».
3. Наблюдения `.hl-observation` — по одной на явление: иконка 44 + текст + для цвета — образцы «было → стало».
4. Объяснение 18/26, 2–3 предложения.
5. «Копнуть глубже» `.hl-deeper` — бирюзовая раскрывашка + научное название чипом.
6. Закреплённая снизу панель: «Записать в журнал» (главная), «Ещё раз».

Ширина 420 (380 компактно), высота — до низа сцены, внутри прокрутка, кнопки всегда видны. Закрыть — крестик или Esc; фокус возвращается на сосуд.

## 12. Наблюдение `.hl-observation`

Строка «иконка + заголовок + подзаголовок» на цветной подложке. Модификаторы: `--change`, `--nothing`, `--success`, `--discovery`, `--caution` (цвета — `02-design-system.md`, раздел «Обратная связь»). Используется в карточке результата, диалогах и журнале.

## 13. Копнуть глубже `.hl-deeper`

Подложка `deep-50`, рамка `deep-100`, кнопка-заголовок 48 px с иконкой лопатки и шевроном (`aria-expanded`). Тело 17/25 с отступом слева 48. Научное название — `.hl-deeper__sci` на белом. Раскрытие — 240 мс по высоте; при сниженном движении — мгновенно.

## 14. Диалог `.hl-dialog`

- Затемнение `ink-900` 55 %. Окно до 600 px, радиус 28, рамка 2 px, `shadow.float`, отступы 28/32.
- Заголовок Unbounded 26, текст 18/27, действия справа: главная — правая.
- `role="dialog"` (или `alertdialog` для остановки), `aria-modal="true"`, фокус на главной кнопке, ловушка фокуса, Esc закрывает (кроме случаев, где нужно явное решение). После закрытия фокус возвращается на элемент, который открыл диалог.
- `--caution` — вариант остановки опыта: янтарная полоса-шапка с Пипой в позе «предупреждает», подзаголовок «Лаба остановила опыт» с иконкой щита, заголовок — что не так («Йод так не нагреваем»), тело — почему (1–2 фразы), плашка-правило, тихая строка «Как можно». Кнопки: «Убрать йод из пробирки» (вторичная, возвращает к последнему безопасному шагу) и «Понятно» (главная). Без рецепта и без названий опасных продуктов.

## 15. Тост `.hl-toast`

Тёмная плашка `ink-900`, белый текст 17/600, иконка 36 на цветной подложке (`--toast-accent`: успех — `success-300`, открытие — `grape-100`), необязательная кнопка (`lamp-300` на тёмном, 7:1). Высота от 56. Вверху сцены по центру. Живёт 4 с, при наведении/фокусе не исчезает; `role="status"`. Не больше одного одновременно — новый заменяет старый.

## 16. Прогресс

- `.hl-progress` — сегменты шагов урока: пройден (`copper-600`), текущий (`lamp-400` с рамкой), будущий (`ink-100`). Подписи шагов над сегментами ≥ 1280, ниже — только у текущего или текстом «шаг 2 из 7» в шапке.
- `.hl-progress-bar` — полоса 14 px с рамкой `ink-900`, заливка лампой (`--value`). `role="progressbar"` + `aria-valuenow/min/max`.

## 17. Значок-награда `.hl-badge`

Шестиугольная медаль 120×136 на ленте; в сетке — 64–88 px. Подпись 15/700 + подсказка 13 «Получен» / как получить. Неполученный — `is-locked`: CSS-фильтр (серый, светлее), без отдельного файла. Новый — `is-new`: появление с `pop` и искрами (`fx/sparkle`) один раз.

## 18. Панель цели миссии `.hl-goal`

```
(◎)  Подпиши все 5 банок            [А][Б][В][Г][Д]  [💡 Пипа, помоги]  [✓ Проверить]
     Каждую надпись докажи опытом
```

- Белая, рамка 2 px, радиус 20, губа, высота от 64.
- Иконка цели 44 на `copper-50`. Заголовок 19/700, подзаголовок 15 (скрыт < 1280).

- «Проверить» неактивна, пока не подписаны все банки.
- На портретном планшете панель переносится в две строки.

## 19. Верхняя панель лабы `.hl-topbar`

64 px, белая, нижняя граница 2 px. Слева «назад» (к карте модуля), режим (`hl-mode--sandbox` «Песочница» лампой / `--mission` «Миссия» купоросом), название. Справа переключатели подсказок и глубины, звук, «Журнал» (< 1280). На < 1280 режим — только иконкой, на < 1024 — скрыт.

## 20. Показание прибора `.hl-readout`

Белая плашка с хвостиком над сосудом: иконка прибора 36 на цветной подложке, значение `readout` 28 px tnum, подпись 14. Для pH — шкала 168 px с рамкой-меткой на текущем значении и слово среды. Держится 4 с после измерения, затем сворачивается в чип на ярлыке сосуда (`.hl-ware__chip`). Обновление значения — `aria-live="polite"`.

## 21. Варианты ответа `.hl-choice` и чипы предсказания

Для тестов и вопросов урока: строка 64 px с буквой-маркером 36, текст 18/600. Выбранный — лампа (`aria-checked`), верный после проверки — `success`, с иконкой галочки. Неверный не красится в красный: показывается объяснение, вариант остаётся нейтральным.

## 22. Полка веществ `.hl-shelf`

Колонка на `wood-100`: заголовок, счётчик «Открыто 12 из 28», группы («Жидкости», «Порошки», «Скоро откроются»), ряды по 2 вещества, каждый ряд стоит на доске (12 px `wood-200` с контуром). На портретном планшете — горизонтальная лента внизу с прокруткой.

## 23. Полка посуды `.hl-rail`

Над столом: доска на стене, на ней посуда и приборы 48–58 px с подписью 14. Нажатие ставит предмет на ближайшее свободное место, перетаскивание — куда положишь. При прокрутке по горизонтали — без видимой полосы, с тенью-подсказкой у края.
