## Как собрать заново

```bash
node design/tools/build-tokens.mjs     # tokens.json → tokens.css + проверка контраста (exit 1 при провале)
node design/tools/build-assets.mjs     # SVG-ассеты + спрайт иконок + manifest.json
node design/tools/build-mockups.mjs    # макеты design/mockups/*.html
node design/tools/build-preview.mjs    # design/preview/index.html
node design/tools/screenshots.mjs      # скриншоты + автопроверки (цели касания ≥ 44, нет горизонтальной прокрутки, нет обрезанного текста)
```

Скрипты `build-tokens` и `screenshots` удобно поставить в CI (GitHub Actions): оба завершаются ошибкой или печатают список проблем.

## Передача во фронтенд

Материалы не привязаны к фреймворку: SVG + CSS-переменные + JSON. Ниже — как их подключать.

### 1. Токены

Подключите `tokens.css` первым. Пути к шрифтам в нём относительные (`../fonts/`): при переносе в проект поправьте их или подключите Google Fonts (ссылка в начале файла).

```html
<link rel="stylesheet" href="/design/tokens/tokens.css">
```

В компонентах используйте семантические токены (`--color-semantic-primary`, `--color-semantic-text-muted`) и токены движения (`--motion-duration-pour`, `--motion-easing-liquid`). Если нужны значения в JS (например, шкала pH для расчёта цвета) — читайте `tokens.json`.

`components.css`, `lab.css`, `effects.css` — **эталонная** вёрстка. Можно взять как есть или переписать в модули своего фреймворка, сохранив имена переменных и визуальные значения. Классы `.is-hover/.is-active/.is-focus` — только для макетов.

### 2. Ассеты

- Статичные иконки — спрайт: `<svg class="hl-icon"><use href="…/sprite.svg#i-heat"/></svg>`, цвет — через `color`.
- Сосуды, тара, персонаж, приборы — **только инлайном** (CSS-переменные не проходят в `<img>`). Загрузите текст SVG, вставьте в DOM, переименуйте `id` уникальным суффиксом (пример — `inlineSvg()` в `design/tools/build-mockups-lib.mjs`).
- Размер на странице — CSS (`width`), высота — `auto`. На столе ширина = натуральная ширина viewBox × `--u`.

### 3. Цвет жидкости и слои анимации

Состояние сосуда — CSS-переменные на корневом `<svg>`:

```js
svg.style.setProperty('--level', 0.55);          // 0…1 доля рабочего объёма
svg.style.setProperty('--liquid-color', '#1F2570');
svg.style.setProperty('--turbidity', 0.8);        // муть
svg.style.setProperty('--sediment', 1);           // осадок
svg.style.setProperty('--bubbles', 1);            // пузырьки видны
svg.classList.add('fx-fizz', 'fx-fizz--strong');  // и анимируются
```

Полный список слоёв (`data-layer`) и переменных — `design/assets/README.md`. Эффекты, тайминги и очередь — `05-effects.md`.

Цвет вещества берите из данных вещества (поле цвета), а токены `color.substance.*` — как справочник и значения по умолчанию.

### 4. Раскладка лабы

`lab.css`: CSS Grid с областями `top / shelf / stage / journal`, переключение на 1279 и 1023 px. Сцена масштабируется одной переменной `--u`. Журнал на < 1280 — фиксированная панель с классом `is-open`.

### 5. Доступность (обязательно)

- Перетаскивание всегда дублируется тап-тапом и клавиатурой (`04-lab-ux.md`, разделы 3–4).
- Каждое изменение сосуда — текстом в `aria-live="polite"`.
- Результат: иконка + текст + цвет, никогда только цвет.
- `:focus-visible` с `--focus-ring`; ловушка фокуса в диалогах.
- `prefers-reduced-motion` и собственная настройка «Спокойные эффекты» → класс `reduce-motion` на `<html>`.

### 6. Согласование с технической спецификацией

`docs/spec/01-product.md` (риски R-09, R-12) предполагает SVG с анимацией через CSS-переменные и явный контракт слоёв — это ровно то, что описано здесь. Контракт слоёв и переменных — `design/assets/README.md`; при изменении слоёв обновляйте `manifest.json` и этот контракт.

## Решения, принятые в дизайне

- **Проводник — Пипа, колба-учёная** (имя из урока 1, образ — колба с жидкостью-телом, которая может менять цвет вместе с опытом). Файлы названы нейтрально `guide-*`.
- **Палитра:** мятный кафель + берёза + чернила `#16213F`; акценты — купорос (действие), лампа (выбор), бирюза (глубже), марганцовка (открытия), янтарь (безопасность). Яркий цвет — только у веществ.
- **Шрифты:** Unbounded (заголовки) + Golos Text (интерфейс), оба OFL с кириллицей.
- **Лаба:** полка веществ слева, стол в центре, док действий под столом («Сделать» / «Наблюдать»), журнал справа; на планшете журнал выезжает, в портрете полка уходит вниз.
- **Отрисовка:** SVG + CSS, без canvas в MVP.

## Открытые вопросы для автора

1. **Образ Пипы.** В уроке 1 Пипа — учёная в халате. В дизайне — колба-учёная с тем же именем и характером (не похожа на чужих персонажей, может менять цвет вместе с опытом). Утверждаем колбу или рисуем человека? Робот Винтик (сцена М0) пока не нарисован — нужен ли он вне этой сцены?
2. **Шрифты: Google Fonts или свои файлы.** Рекомендую хостить подмножество из `design/fonts/` на GitHub Pages: ни одного запроса к третьей стороне — проще с требованиями к данным детей. Подходит?
3. **Количество в миссии.** Урок 1 требует «1 тап = 1 порция» без выбора количества; в песочнице — поповер с выбором. Оставляем два разных способа или и в миссии показывать поповер (единообразно, но медленнее)?
4. **Нагрев «пока держишь».** На планшете удерживать кнопку неудобно и плохо для доступности. Предлагаю «Нагреть» как переключатель (нажал — горит, нажал ещё — погасло) с автоостановкой через 30 с. Согласны отойти от формулировки урока?
5. **Звуки и вытяжка.** Звуки заложены в UX, но не спроектированы (нужен отдельный набор, свой или CC0). Также не нарисованы: раковина, вытяжка, держатель с пробиркой над огнём, перелив пены и рука «веером» — их добавить следующим шагом, когда утвердим стиль?
