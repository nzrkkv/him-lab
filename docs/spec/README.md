## Ключевые решения кратко

1. **Статический сайт без бэкенда.** SPA на Vite + TypeScript (strict) + Preact, маршруты через `#`, деплой на GitHub Pages через GitHub Actions. Ни одного запроса к сторонним адресам, без cookie, без персональных данных; прогресс — в `localStorage` с версионированной схемой и миграциями.
2. **Чистое ядро.** Движок реакций, миссии, уроки и прогресс — чистые детерминированные функции без DOM, времени и случайности. Интерфейс только показывает состояние и передаёт действия. Это главное условие для кода, который пишет ИИ-агент, а ревьюит человек: всё проверяется таблицами «вход → выход».
3. **Контент — данные.** Вещества, правила, эффекты, уроки, миссии, тесты, награды и все тексты — YAML в `content/`, проверяемые схемой Zod и линтерами (ссылки, баланс уравнений, покрытие пар «реакция или объяснение», решаемость миссий, безопасность текстов). Тексты хранятся как `{ ru, en? }` — английский добавляется без изменения кода.
4. **Честная химия с путём к молям.** Внутри — граммы по каждой химической частице, молярные массы, растворимость по таблицам, стехиометрия вариантов правил. Ребёнок видит порции; продвинутый режим получит моли и концентрации без смены модели.
5. **Правила по классам.** «Кислота + карбонат → газ» с вариантами для конкретных пар (сода, мел). Порядок применения детерминирован: приоритет, специфичность, `id`. «Ничего не произошло» — тоже результат с объяснением. Опасные сочетания проверяются до действия и останавливают опыт без «рецепта».
6. **Отрисовка — SVG дизайна + CSS-переменные.** Состояние сосуда (`--level`, `--liquid-color`, `--turbidity`, `--foam`…) задаёт фронтенд, эффекты — классы `fx-*` из `effects.css`; никаких растровых картинок; сниженное движение и доступность встроены.
7. **Сначала прототип лабы, потом уроки.** Вехи M0–M3 — прототип с миссией «Загадка белых порошков» и песочницей; затем ворота G1: дети играют 10+ минут сами. Только после этого — плеер уроков и контент.

## Рабочие решения до ответа автора

Приняты так, чтобы их было легко поменять (подробно — `06-open-questions.md`):
- проводник — Пипа, колба-учёная (ассеты `guide-*`, в коде — `guide`);
- шрифты хостим сами из `design/fonts/`;
- «Нагреть» — переключатель с автоостановкой через 30 с;
- в миссии «1 тап = 1 порция», в песочнице — выбор количества;
- без сетевой аналитики в MVP, только журнал плейтеста;
- превью PR — артефакты и скриншоты, живые превью — после M3.

## Что нужно от автора в первую очередь

1. Q-01: GitHub Pages для приватного репозитория (публичный репозиторий или платный тариф) — блокирует деплой.
2. Q-02: домен до публичного релиза — от него зависит сохранность прогресса детей.
3. Q-03: аналитика — рекомендуется не включать в MVP.
4. Q-04: образ проводника (колба или человек).
5. Q-09: песочница доступна сразу со стартовым набором или только после урока 1.
